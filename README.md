# DevExplorer 🚀

A simple web development project created during a hands-on workshop for 2nd-year students.

Built using **HTML, CSS, and JavaScript**, it features an interactive resource directory with live search and category filters.

## 🌐 Live Demo

**https://syesh.github.io/dev-explorer/**

## ✨ Features

- Live search for resources.
- Category-based filtering.
- Responsive card layout.
- Interactive buttons and UI.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)

## 🚀 Getting Started

Clone the repository:

```bash
git clone YOUR_REPOSITORY_URL
```

Open `index.html` in your browser or use VS Code Live Server.
